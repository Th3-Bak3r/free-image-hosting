**[วิธีอัปโหลดรูปภาพ](https://hostmyimg.com/)**

เปิดเว็บไซต์ เลือกไฟล์ และรอให้อัปโหลดเสร็จ จากนั้นคัดลอก URL โดยตรง, BBCode สำหรับเว็บบอร์ด หรือโค้ด HTML สำหรับหน้าเว็บ เปิดลิงก์เพื่อตรวจสอบผลลัพธ์
