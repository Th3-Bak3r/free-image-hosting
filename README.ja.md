# HostMyImg — 無料画像ホスティング・画像アップロード・画像のURL化

HostMyImg に写真、スクリーンショット、GIFをアップロードし、リンクで共有できます。匿名アップロードにはアカウントが不要です。

**[画像をアップロードする](https://hostmyimg.com/)**

## 画像をアップロードする

サイトを開き、ファイルを選んでアップロードの完了を待ちます。直接URL、掲示板用のBBCode、またはウェブページ用のHTMLコードをコピーし、リンクを開いて結果を確認してください。

## 画像や写真をURLに変換

端末内の画像や写真から共有用リンクを作成します。複数のファイルには一括アップロードのページを利用できます。

[画像をURLに変換](https://hostmyimg.com/image-to-url) · [写真をURLに変換](https://hostmyimg.com/photo-to-url) · [一括アップロード](https://hostmyimg.com/bulk-image-hosting)

## 一時的な画像ホスティング

サポート用のスクリーンショットや制作途中の案を共有できます。保存期間を選ぶ前に、自動削除の設定と保存条件を確認してください。匿名アップロードだけでは特定の削除日時は保証されません。

[一時的な画像ホスティング](https://hostmyimg.com/temporary-image-hosting)

## 無料GIFホスティングとDiscordでのGIF共有

GIFをアップロードし、直接リンクをDiscordの会話に貼り付けます。プレビューの表示はDiscordの設定や権限に依存するため、投稿先のチャンネルで確認してください。

[無料GIFホスティングとDiscordでのGIF共有](https://hostmyimg.com/gif-hosting)

## 自分に合った画像ホスティングサイトの選び方

ファイルサイズの上限、対応形式、直接リンク、保存期間、埋め込み機能を比較しましょう。HostMyImg の比較ガイドも参考にできます。

[自分に合った画像ホスティングサイトの選び方](https://hostmyimg.com/blog/best-image-hosting-sites)

## よくある質問

アカウントは必要ですか？匿名アップロードには不要です。無料ですか？サービスの制限と利用条件の範囲内で無料です。画像は非公開ですか、永久保存されますか？そうとは限りません。ファイルはホスティングサービスに送信されるので、元の画像を手元に保存してください。

## ツールと関連情報

必要に応じて共有前に画像を圧縮したりサイズを変更したりできます。画像ツールやサービスのポリシーを確認するか、サポートにお問い合わせください。
